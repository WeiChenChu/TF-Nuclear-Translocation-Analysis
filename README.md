# 🔬 TF-Nuclear-Translocation-Analysis

**Custom Python scripts for refining time-lapse cell tracking data, implementing edge and trajectory filtering, and quantitatively calculating the Dot6-GFP Nuclear Translocation Index from live-cell microscopy.**

This repository contains the post-processing and quantitative analysis scripts developed for measuring stress-induced nuclear translocation of the Dot6-GFP transcription factor in yeast time-lapse images. These scripts execute the subsequent analyses following initial image acquisition, segmentation, and tracking (performed in Fiji/ImageJ).


## 🛠 Prerequisites

These scripts assume that the initial image processing has been completed, resulting in aligned time-series intensity and label images (T, Y, X dimensions).

### External Processing Steps:

1.  **Acquisition:** Time-lapse Z-stack live-cell images (GFP fluorescence and Brightfield).
2.  **Segmentation:** Brightfield images segmented using Cellpose (Cytoplasm 2.0, $5\text{-}\mu\text{m}$ diameter).
3.  **Tracking:** Masks imported into ImageJ/Fiji (TrackMate) for cell tracking (Simple LAP tracker, $5\text{-}\mu\text{m}$ max linking distance, no splitting/merging).

## ⚙️ Workflow Overview 

The analytical pipeline is divided into two sequential parts, operating on the output multi-dimensional TIFF files (intensity and labels) generated by the tracking software.

| Step | Script | Function | Input Data Source |
| :--- | :--- | :--- | :--- |
| **Part I** | `label_filtering.ipynb` | **Filtering:** Removes cells touching the image border and excludes incomplete cell trajectories (cells not present in all time frames). | TrackMate Labels (`*_label.tif`) |
| **Part II** | `nuclearization_ratio_calculation.ipynb` | **Quantification:** Computes the nuclearization ratio, filters outliers, and calculates the final quantitative **Dot6-GFP Nuclear Translocation Index**. | Part I Filtered Labels (`*_filtered_label.tif`) |
